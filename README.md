### 📍 주요 기능 및 데모 환경 구성
- 선호 영화 선택 결과를 기반으로 장르별 추천 영화를 제공하고, 영화 및 사용자 컬렉션을 탐색할 수 있는 화면을 구현했습니다.
- 백엔드 없이도 주요 화면을 확인할 수 있도록 영화·컬렉션 Mock 데이터와 로컬 이미지 에셋을 추가했습니다.
- 외부 API Key가 필요한 챗봇은 포트폴리오 데모 범위에서 의도적으로 제외하고, 환경 설정과 Route Guard를 통해 버튼 및 직접 접근을 비활성화했습니다.
- 영화 목록과 컬렉션 상세 화면이 Mock 데이터와 실제 API를 동일한 서비스 인터페이스로 사용할 수 있도록 구성했습니다.

## 💡 시작하기

```bash
1. 저장소 클론
git clone git clone https://github.com/사용자명/저장소명.git

2. 프로젝트 폴더로 이동
cd 저장소명

3. 패키지 설치
npm install

4. 개발 서버 진행
npm run dev
```
